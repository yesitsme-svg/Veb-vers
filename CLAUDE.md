# Motion Grid — правила работы

Инструмент: https://wannathis.one/online-tools/motion-grid/app
Всё приложение — один файл `index.html`, без сборки и зависимостей.

## Не сломай это

**Абсолютные CDN-пути — так задумано.** В `index.html` нет ни одного
относительного пути: шрифты, картинки и ffmpeg грузятся с CloudFront по
абсолютным URL. Это выглядит как ошибка, но переписывать их на относительные
НЕЛЬЗЯ — сломается прод.

**Папка `cdn/` — зеркало бакета, а не ассеты приложения.** Путь внутри `cdn/`
= путь в бакете. Не переименовывай и не перекладывай файлы: структуру уже
чинили один раз именно из-за этого. На прод она не деплоится.

**Блок `<head>` не трогать.** canonical на `/app`, `og:url`, favicon,
apple-touch-icon, sitemap, og/twitter image, title. Эти строки однажды уже
потеряли между версиями.

**Скрипты аналитики оставить:** DataFast, GTM (`GTM-WXFVD29`), Rewardful
(`f09e09`). Это трекинг всего сайта.

## Проверка локально

```
python3 -m http.server 8000    # http://localhost:8000
```

Через `file://` экспорт видео падает на CORS. Только через сервер.

## Добавление новой демки

Два шага, оба обязательны, иначе картинка молча отдаст 404:

1. положить файл в `cdn/images/motion-grid/` и залить его в бакет по тому же пути;
2. увеличить `length:20` в строке `DEMO_URLS` в `index.html`.

## Версии

- `main` — рабочая ветка. Коммить и пушь свободно, автодеплоя нет, на живой
  сайт это не влияет.
- **Теги и релизы не создавать.** Тег означает «одобрено для прода» — это
  решение владельца репы. Если считаешь, что версия готова, скажи словами.
- На прод уезжает **только `index.html`**, один файл.

## Прочее

- Приложение только для десктопа — на телефонах показывается `#mobileGate`.
- Экспорт видео: `@ffmpeg/core@0.12.6` с unpkg, в браузере через WASM. Никуда
  ничего не загружается.
- Подробности про деплой — в `README.md`.
- Лендинг `/online-tools/motion-grid` (без `/app`) — отдельная страница внутри
  основного сайта на Nuxt. К этому проекту не относится, не трогать.
