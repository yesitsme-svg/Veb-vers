# Motion Grid — продолжение работы

Распакуй папку, открой в ней Claude Code. `CLAUDE.md` подхватится сам — там
правила проекта. Объяснять ничего не нужно, всё ниже.

## Что сделано

К исходным 23 темплейтам добавлено **3 новых**, старые не тронуты:

| Пресет | Категория | Что это |
|---|---|---|
| **Push Stack** | Cards | Уходящий вверх стек. Импульс стартует с задней карточки и идёт вперёд по одной (домино), передняя выталкивается вниз за кадр |
| **Push Cascade** | Cards | Тот же импульс, но по диагонали кадра — слева направо, ведущая вылетает за нижний-правый угол |
| **Spinner** | 3D Space | Карточки радиальными лопастями на вертикальном колесе: передняя стоит ребром, верхняя лицом, нижняя вверх ногами |

## Как запустить

```
python -m http.server 8765
```

Открывать **через сервер**, не двойным кликом: по `file://` экспорт видео падает на CORS.

## Откат

Снапшоты в `backups/`, к любому шагу:

```
cp backups/003-push-cascade.html index.html
```

- `000-baseline.html` — исходник из зипа Антона (коммит `0f078cf`)
- `001-push-stack.html` — Push Stack как был сначала
- `002-push-stack-tuned.html` — после правок по плавности
- `003-push-cascade.html` — + Push Cascade
- `004-spinner.html` — + Spinner (**текущий**)

История git тоже внутри: `git log --oneline`, `git checkout <hash> -- index.html`.

**`backups/CHANGELOG.md` — главный файл.** Там по каждой правке записано что
замерялось в референсе, какие числа получились и почему выбрано именно так.
Включая тупики: в Spinner я трижды собрал не то, все три ошибки разобраны — без
этого легко наступить второй раз.
